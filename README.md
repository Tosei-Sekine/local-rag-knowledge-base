# 特定ドメイン専用・根拠明示型ローカルRAGナレッジベース

社内の機密ドキュメントやコードを、**完全ローカル環境**で、**根拠（参照箇所）を示しながら**日本語で解説するRAG（Retrieval-Augmented Generation）システムです。クラウドAIに送れない情報を、漏洩リスクなく・ハルシネーションを抑えて扱うことを目的としています。

> デモの題材には Kaggle / SIGNATE のコンペ資料を使用していますが、知識ベースを差し替えれば**どの業界のドキュメントにも対応できる汎用設計**です。

---

## 背景・課題

- 内製化が求められる一方、社内に仕様書やノウハウが蓄積されず**ブラックボックス化**している。
- エンジニアの**人材不足**（レバテック2026年調査では約4社に1社が採用目標未達）。
- **クラウド型AIが使えない**：機密情報を外部サーバへ送信できず、ハルシネーションやAIガバナンス（AI事業者ガイドライン／EU AI法）の壁もある。

結果として、若手エンジニアは最も価値のある「社内固有のノウハウ」の習得でAIの恩恵を受けられていない。

## 目的・解決策

**完全ローカルの根拠明示型AI**であれば、情報漏洩リスクをゼロにしたまま、関連ドキュメントを根拠つきで解説できる。これにより、即戦力化までの期間短縮と、ドキュメント検索時間の削減による開発効率の向上を狙う。

---

## 主な特徴

- **完全ローカル実行** — 生成・検索・リランクのすべてをローカルで完結。入力データが外部に出ない。
- **根拠明示型（Root-cited）** — 回答と同時に参照したチャンクを提示し、ハルシネーションを人が検証できる。
- **ハイブリッド検索＋リランカー** — BM25（キーワード）＋ベクトル検索で候補を集め、クロスエンコーダで上位に絞り直す。
- **定量評価** — Ragas の5指標で精度を数値化。クラウド（Amazon Bedrock）との公平な比較も実施。
- **計測の可視化** — 回答時間・入力/出力トークン・コスト（ローカルは¥0）を画面表示。クラウド換算の参考値も併記。

## 評価（Ragasの5指標）

「本（資料）を開きながら答える生徒」に例えると分かりやすい。

| 指標 | 平たく言うと |
|---|---|
| context_recall | 必要な資料を**取りこぼさず**拾えたか（検索の網羅性） |
| context_precision | 拾った資料に**ハズレが混じっていない**か（検索の的確さ） |
| faithfulness | 資料に書いてあることだけで答えているか（でっち上げの逆） |
| answer_relevancy | 聞かれたことに**ちゃんと答えている**か |
| answer_correctness | 模範解答と照らして**実際に合っている**か |

**クラウド（Bedrock）との比較の要点：**
検索精度（recall / precision）は**Bedrockとほぼ同等**に到達。最終的な回答の正確性（correctness）は**モデル規模の差**でBedrockが上、という結果。「勝った」ではなく「**同じ基準で測り、どこが強くどこが弱いかまで把握した**」という位置づけ。

> 各指標の数値は実行ごとに多少変動します。最新の確定値はリポジトリ内の実験記録（`RAG実験記録.xlsx` 等）を参照してください。
> また、answer_correctness は1単語の正解に対して機能不全を起こすため、正解データを「自然な一文」に書き直して物差しを校正しています（詳細は CHANGELOG 参照）。

## 実行方法（Google Colab）

1. `ローカルRAGデモ_完成版.ipynb` を Colab で開く
2. **ランタイム → ランタイムのタイプを変更 → T4 GPU** を選択
3. 最後のセルの `NGROK_AUTHTOKEN`（環境変数）に自分のngrokトークンを設定
4. **ランタイム → すべてのセルを実行**
5. 出力される `✅ APP URL`（ngrokのURL）を開く
6. 「テキスト/コードを貼り付け」タブに知識ベースを貼り、「解説を準備」→ 質問

> 初回は Ollama のインストールと `qwen3:14b`（約9.6GB）の取得で数分かかります。

## 今後の展望

- **マルチモーダルRAG** — グラフ・表・図を、ローカルのVLMで説明テキスト化して取り込み。

- **AWSでのホスティング** — ngrokからの脱却。
- **ファインチューニング（LoRA/QLoRA）** — 自社ドメインへの特化。
